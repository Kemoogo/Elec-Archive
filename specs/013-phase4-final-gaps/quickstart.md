# Quickstart & Verification Guide: استكمال المرحلة الرابعة

**Feature**: `013-phase4-final-gaps` | **Branch**: `feature/phase4-final-gaps`

## 1. فحص الجودة الساكن والبناء
```bash
cd next
npx tsc --noEmit
npm run lint
npm run build
cd ..
graphify auto-update .
```

## 2. سيناريوهات التحقق اليدوي

### أ. تعديل مسمى التصنيف التخصصي (`FR-06.1`)
1. الانتقال إلى `/students` وفتح تبويب **المرحلة الحالية**.
2. فتح نافذة **تخصيص التصنيفات التخصصية للدفعة**.
3. الضغط على أيقونة القلم (`تعديل مسمى التصنيف`) لأحد التصنيفات التي ينتمي إليها طلاب، وتعديله إلى اسم جديد غير مكرر ثم الحفظ.
4. التأكد من:
   - ظهور إشعار النجاح.
   - تحديث الاسم في قائمة التصنيفات وفي جدول طلاب المرحلة ومصفوفة التوزيع.
   - رفض الأسماء الفارغة أو المكررة.
   - بقاء سجلات التمام اليومي للأيام السابقة دون تغيير.
   - تسجيل عملية `UPDATE` في `/audit-log`.

### ب. الاستعادة من أرشيف خارجي (`FR-07.4`)
1. الانتقال إلى `/admin/backup` كمدير نظام (`Admin`).
2. تصدير نسخة احتياطية فورية (`.tar.gz`) لحفظها محلياً ثم الضغط على **استعادة من أرشيف خارجي**.
3. اختبار حالات الرفض:
   - ملف بامتداد غير `.tar.gz` أو `.tgz`.
   - ملف فارغ (0 بايت) أو يتجاوز 2 جيجابايت.
   - عبارة تأكيد خاطئة أو كلمة مرور غير صحيحة (وتحقق من تسجيل `LOCK` في `/audit-log`).
4. اختبار حالة النجاح:
   - رفع ملف `.tar.gz` صالح وإدخال عبارة التأكيد وكلمة المرور الصحيحتين.
   - التأكد من نجاح الاستعادة وظهور النسخة المرفوعة في جدول النسخ مع الحفاظ على حد أقصى 4 نسخ (تدوير أي نسخة زائدة).
